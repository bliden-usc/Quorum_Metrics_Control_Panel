Re-run after fixes

Use this after staff fix Notes in Quorum. Download only the files that changed (usually just the Notes export) into the Quorum Downloads folder in Box, wait until Check File Status no longer lists them as missing, then click below. The system fills in every other file from the last run's saved set and runs as normal, with the report options chosen above. The "Pipeline Complete" email says which files were filled in.

If a person's details changed in Quorum (for example naming an "Unnamed Contact"), also download that person's file: Contacts, Staff or Officials, together with Notes. If a fix involves an Outbox email, do a full fresh download of all 6 files and use Run System instead.

Re-run with last week's files: No new downloads needed: reuses all 6 files from the last complete run. Use when nothing changed in Quorum and you just need fresh reports. The Quorum Downloads folder must be empty; if it has any files, use Re-run after fixes instead.

Do not trigger twice.
Admin Controls ▼

Dev Mode

When Dev Mode is ON, all system emails route exclusively to the Administrator. The system runs normally — only email routing changes. The warning banner at the top will be visible as a reminder. Turn Dev Mode OFF before triggering a production run.
